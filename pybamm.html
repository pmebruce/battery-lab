主要情境的發熱分量

發熱分量依 PyBaMM 的歐姆熱、不可逆電化學反應熱及可逆熱定義；本例未加入接觸電阻、遲滯或混合熱。溫度為 lumped 模型平均值，不能視為最高芯溫。每組範例取樣 121 點；平均發熱與累積熱量採梯形積分，峰值為取樣峰值。不同容量與幾何的參數集不宜只比較發熱絕對值。

匯出 CFD 熱源

體積熱源 q‴(t) = 電芯數 × 單顆 Q(t) ÷ CFD 發熱物件總體積。電芯數改變時，體積會先依參數集的單顆體積更新，再由你調整實際 CFD 體積。數量僅縮放相同電芯的熱量，不是電池包電路或溫差耦合模型。

自訂條件與本機求解

如何在電腦執行

電腦需先安裝 Python；安裝指定版本後執行下載的檔案。模型會在最長時間或截止電壓事件時停止。

python -m pip install pybamm==26.10.1.0
python battery-pybamm.py

產生 pybamm-result.json 與 CSV，再將 JSON 匯入下方，即可使用同樣的繪圖與 CFD 匯出。

SPM 忽略電解液的濃度與電位分布；SPMe 加入電解液效應。高倍率的適用性仍需以你的電芯實驗核對。
